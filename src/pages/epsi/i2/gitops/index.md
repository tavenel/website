# GitOps et automatisation avancée

## Présentation du module

### 🎯 Objectifs du cours

Ce module introduit les principes du **GitOps** et leur mise en œuvre avec **Argo CD** sur Kubernetes.

L'objectif est de comprendre comment un dépôt Git peut devenir la source de vérité d'un environnement Kubernetes et comment Argo CD assure la réconciliation entre l'état souhaité et l'état réel du cluster.

- expliquer les principes fondamentaux du GitOps ;
- distinguer approche impérative et approche déclarative ;
- expliquer le rôle de Git comme source de vérité ;
- expliquer le fonctionnement de la réconciliation ;
- installer Argo CD sur un cluster Kubernetes ;
- déployer une application Kubernetes depuis Git et Argo CD.

### 📋 Prérequis

- Connaissances de base de Kubernetes et des principes d'orchestration de conteneurs
- Git
